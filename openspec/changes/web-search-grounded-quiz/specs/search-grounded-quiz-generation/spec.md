## Purpose

让 AI 出题链路能够获取实时联网资料：既可根据关键词联网搜索，也可按用户输入的网址提取整页内容，并由 AI 自主决定是否调用、调用哪个工具及如何选择参数，从而解决大模型训练数据截止导致新概念被套用到旧领域、以及网页类输入无法学习的问题。

## ADDED Requirements

### Requirement: 关键词搜索与网址提取双通道

系统必须在出题智能体中同时提供两类联网资料获取能力：基于关键词的网络搜索（返回结果标题、链接与内容摘要）与基于网址的整页内容提取（返回页面全文）。当用户学习输入中包含网页 URL 时，系统必须使智能体能够提取该网页内容作为学习材料；当输入为关键词或一段话时，系统必须使智能体能够执行网络搜索。

#### Scenario: 关键词输入走搜索
- **WHEN** 用户输入一段学习主题或文字描述
- **THEN** 智能体可发起网络搜索并获取结果标题、链接与摘要

#### Scenario: 网址输入可提取整页
- **WHEN** 用户输入中包含一个或多个网页 URL
- **THEN** 智能体可提取对应网页的正文内容作为资料，且该网页出现在响应来源中

#### Scenario: 网址与主题混合输入
- **WHEN** 用户在输入中同时给出网页链接和补充说明文字
- **THEN** 智能体既可提取网页内容，也可围绕补充说明发起搜索

### Requirement: AI 自主决策工具调用与参数

两个联网工具必须以工具调用形式提供给模型，由模型自主决定是否调用、调用哪个工具、调用顺序与次数，并自主填写工具参数。系统必须在智能体系统提示词中提供参数选择指导，使模型能够根据主题特征动态选择：内容复杂或模型生疏的知识采用更深的内容获取方式（如高级搜索深度或整页提取），简单知识仅获取搜索摘要；时效性强的话题使用新闻类别或时间范围过滤；地域与语言相关性通过动态设置包含/排除域名及检索词语言来调节（官方工具未暴露国别参数，以域名圈定替代）。

#### Scenario: 复杂生疏主题加深获取
- **WHEN** 用户输入是模型训练数据截止后出现的新概念
- **THEN** 模型采用更深的获取方式（高级搜索深度，或进一步提取来源网页全文）后再出题

#### Scenario: 简单主题轻量获取
- **WHEN** 用户输入是常识性、模型熟悉的主题
- **THEN** 模型可采用基础搜索深度直接获取摘要出题，甚至自行判断无需检索而直接出题

#### Scenario: 时效性话题的时间过滤
- **WHEN** 用户输入明显属于近期动态类话题
- **THEN** 模型可动态使用新闻类别或时间范围参数限定检索窗口

#### Scenario: 中文主题的地域相关调节
- **WHEN** 用户以中文输入中国语境的话题
- **THEN** 模型可动态圈定中文内容站点域名并以中文构造检索词；英文及国际话题同理反向适用

### Requirement: 题目内容以检索资料为事实依据

智能体系统提示词必须包含事实性约束：当获得检索资料时，题目与讲解必须以资料为主要事实依据；资料与模型既有知识冲突时以资料为准；资料未覆盖的角度不得编造细节；禁止将主题解释为其他领域的同名概念。

#### Scenario: 新概念不再跑偏
- **WHEN** 智能体获取到明确描述主题的资料后生成题目
- **THEN** 题目、答案和讲解与资料口径一致，不出现跨领域套用

#### Scenario: 资料与既有知识冲突
- **WHEN** 模型既有知识与检索资料存在冲突
- **THEN** 生成的题目采用检索资料的口径

### Requirement: 资料获取失败的差异化兜底

系统必须区分三类失败路径并差异化处理：其一，模型未调用任何工具，或所有工具调用均因服务故障（超时、连接失败、鉴权失败、服务端错误）而未获得资料——系统必须降级为纯模型出题并正常返回题库，同时在响应中标注未经联网核实，并记录告警日志；其二，模型调用了工具且调用成功但所有结果均为空或网页提取全部失败——系统必须返回明确的业务错误，提示用户更换说法、补充背景或确认链接有效，不得静默产出可能跑偏的题库；其三，联网功能被服务端配置关闭——系统必须完全跳过智能体，直接纯模型出题并标注未经联网核实。

#### Scenario: 模型自主跳过检索
- **WHEN** 模型判断无需检索而直接生成题库
- **THEN** 请求正常返回，响应标注本次未经联网核实

#### Scenario: 搜索服务故障
- **WHEN** 工具调用因网络超时、鉴权失败或服务端错误全部失败
- **THEN** 系统降级为纯模型出题并正常返回，响应标注未经联网核实，同时记录告警日志

#### Scenario: 检索成功但一无所获
- **WHEN** 工具调用成功但搜索零结果，或网址提取全部失败
- **THEN** 接口返回明确的业务错误与可操作的中文提示，响应中不包含题目

#### Scenario: 功能开关关闭
- **WHEN** 服务端配置关闭联网功能
- **THEN** 出题请求照常返回纯模型题库，响应标注未经联网核实

### Requirement: 响应携带检索元数据

出题响应必须携带检索元数据：`search_used` 布尔标记（本次是否经过联网资料获取）与 `sources` 列表（资料标题与链接，来源涵盖搜索结果与被提取的网页，数量不超过实际采用的资料条数）。这些字段必须为可选字段以保证向后兼容；不含元数据的历史题库与续答题库必须仍能正常渲染。

#### Scenario: 联网出题响应
- **WHEN** 智能体获取到资料并完成出题
- **THEN** 响应中 `search_used` 为 true 且 `sources` 非空

#### Scenario: 降级出题响应
- **WHEN** 模型跳过检索或工具故障触发降级
- **THEN** 响应中 `search_used` 为 false 且 `sources` 为空

#### Scenario: 历史题库向后兼容
- **WHEN** 前端读取未包含检索元数据的历史题库或续答题库
- **THEN** 题库照常渲染，不因缺少新字段而失败

### Requirement: 注入 Prompt 的资料规模受控

系统必须限制注入出题 Prompt 的资料规模：单条搜索摘要、单页提取正文与资料总量必须受到截断控制，使 Prompt 不超过模型输入限制、出题延迟与费用保持在合理范围。

#### Scenario: 整页提取内容被截断注入
- **WHEN** 智能体提取到篇幅很长的网页正文
- **THEN** 系统仅将限长后的正文注入 Prompt，出题仍然成功

#### Scenario: 多来源资料受总量约束
- **WHEN** 智能体累计获取到大量搜索结果与网页内容
- **THEN** 系统按总量预算截断注入，保证最终 JSON 输出不被挤压

### Requirement: 智能体运行受控

智能体的工具调用循环必须受步数上限与总时长上限约束；超过任一上限时，系统必须中止智能体并降级为纯模型出题，在响应中标注未经联网核实，同时记录告警日志。智能体出题的最终答案必须与现有出题链路一致，为可解析、可校验的结构化题库 JSON。

#### Scenario: 循环超限降级
- **WHEN** 智能体反复调用工具达到步数上限或总时长上限仍未产出最终答案
- **THEN** 系统中止智能体、降级为纯模型出题并正常返回，响应标注未经联网核实

#### Scenario: 最终答案保持结构化
- **WHEN** 智能体产出最终题库
- **THEN** 输出通过现有的 JSON 解析与字段完整性校验后才返回给前端

### Requirement: 两个出题入口行为一致

联网资料获取能力必须同时覆盖 `/api/v1/quiz/generate` 与 `/api/v1/quiz/drill` 两个出题入口，二者的兜底行为与响应元数据语义一致。专项训练输入为模板句式时，系统必须引导模型构造聚焦薄弱点主题本身的检索词，而不是检索整段模板文字。

#### Scenario: 专项训练同样具备联网能力
- **WHEN** 已登录用户请求薄弱点专项训练出题
- **THEN** 专项出题与普通出题使用相同的智能体链路、兜底行为与元数据语义

#### Scenario: 模板句聚焦核心主题
- **WHEN** 出题输入是「我正在专项突破薄弱知识点『向量数据库』……」形式的模板句
- **THEN** 模型构造的检索词聚焦「向量数据库」本身，而非整段模板文字
